# 洪灾制图与面积预算复核：主线代码

本仓库整理从公开卫星数据预处理到训练、冻结推理和最终评价的研究主线。
包括 SAR/光学–SAR 专家、事件嵌套交叉拟合、价值门控、遗漏评分、开发集校准、
TerraMind 对照、三成员融合集成、面积预算复核和配对空间统计。
仓库不包含作图代码、论文文档、原始数据、训练权重或本地运行产物。

## 运行与复现

- [完整运行顺序与环境说明](docs/REPRODUCING.md)：原执行平台为 Windows、单张 NVIDIA GPU、CUDA 12.8；主环境 Python 3.9，基础模型环境 Python 3.11。
- [数据来源与目录](docs/DATA.md)：Sen2GF3Floods 公开下载、完整文件校验和预处理。
- [发布来源记录](docs/PROVENANCE.md)：逐文件 SHA-256、历史冻结记录与本次包装修改。
- [软件验证](docs/VALIDATION.md)：使用合成数据验证评价实现，不启动新训练。

预定批次为 38 项拟合，另有前置的 3 项开发筛查训练。保留样本共 17,019 个，
其中 8,786 个用于开发、8,233 个用于冻结的 2023 年核心测试。
所有评价遵循固定划分和协议；有利、无效及相反方向的结果均保留。

价值目标为 `v*=(s-y)^2-(f-y)^2`，通过事件留出预测构造；
门控 `g=sigmoid(tanh(h(z))/0.05)`，输出 `p=s+g*(f-s)`。
复核按 64×64 像素单元排序，在共同有效面积预算内选择完整单元。
剩余漏检/误报面积来自对选中单元进行理想校正的计算实验，评价参照是发布方的二值标签。

首次使用请按复现文档顺序运行。`provenance/` 中的历史冻结文件用于追溯，
不能充当新运行的完成凭证；新训练需要生成自己的审计、校准及冻结记录。
本次整理未重新执行完整 GPU 实验，也未改变模型、损失、划分、轮次和评价公式。
